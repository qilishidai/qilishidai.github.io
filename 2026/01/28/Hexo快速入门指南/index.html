分类 vs 标签：如何选择？

分类（Categories）

  • 数量：一篇文章只能有一个分类
  • 用途：区分大主题（”技术” vs “生活”）
  • 影响：决定导航菜单显示

标签（Tags）

  • 数量：一篇文章可以有多个标签
  • 用途：标记细化主题（”JavaScript”、”前端”、”异步编程”）
  • 影响：帮助读者查找相关内容

建议：用分类来区分大方向，用标签来细化内容类型。

常见问题

Q1: 文章什么时候会显示在首页？

A: 检查三点：

  1. ✅ 文章有 title: 字段
  2. ✅ date: 字段小于或等于当前时间
  3. ✅ 执行了 npm run build

Q2: 修改配置后不生效？

A: 执行 npm run clean && npm run build 清理缓存。

Q3: 如何删除已发布的文章？

A: 删除 source/_posts/ 中的文件，然后重新编译即可。
